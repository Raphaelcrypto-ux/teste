## Projeto — Formulário Acadêmico
Projeto desenvolvido para a disciplina de Programação, com o objetivo de praticar conceitos básicos de HTML e CSS.

O projeto consiste na criação de um formulário acadêmico com informações pessoais e dados relacionados ao curso.

##  Sobre o projeto
Este projeto consiste na criação de um formulário acadêmico, contendo campos para informações pessoais e dados relacionados ao curso.

Após o preenchimento, o formulário direciona o usuário para uma página de confirmação.

## Tecnologia

HTML5

CSS3

## Objetivo
Praticar os conhecimentos aprendidos durante as primeiras aulas de programação, desenvolvendo um formulário utilizando HTML e CSS.
